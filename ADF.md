# Original Amiga disk image

The original ADF is not included in this repository.

The reference version is listed on
[Planet Emulation](https://www.planetemu.net/en/rom/commodore-amiga-games-adf/time-bandit-v2-2-1988-microdeal-cr-a-ha):

```text
Time Bandit v2.2 (1988)(Microdeal)[cr A-Ha]
```

Download and use the disk image only when permitted by the laws that apply to
you and by the original rights holders. The desktop and Android builds include
their runtime assets and do not need the ADF.
